# 주중 목양 현황

단톡방에 올리듯 채팅으로 적어 보내면, 주차별로 구글 시트에 정리해 주는 웹 서비스입니다.

```
성경 - 철수, 영희
문자 - 민수
```

**봉사자**가 앱에 들어와 본인 이름을 고르고, 그 주에 목양한 **학생** 이름을 적습니다.
위처럼 보내면 &ldquo;이번 주에 홍길동(봉사자)이 성경으로 철수·영희(학생)를 목양했다&rdquo;로 기록되고,
아래 두 장의 표가 자동으로 다시 그려집니다.

| 시트 | 내용 |
| --- | --- |
| `봉사자명단` | 목양하는 사람. 이름 · 담당 그룹 |
| `학생명단` | 목양받는 사람. 이름 · 그룹 · 학년 |
| `기록` | 원본 로그. 한 줄 = 어느 봉사자가 / 언제 / 어떤 항목으로 / 어느 학생을 목양했는지 한 건 |
| `받은목양` | 행 = **학생**, 칸 = 그 주에 그 항목으로 목양받은 횟수를 **색 농도로**(히트맵). 칸에 마우스를 올리면 어느 봉사자였는지 보입니다. |
| `한목양` | 행 = **봉사자**, 칸 = 그 주에 목양한 학생들의 이름 |

두 요약표는 행의 성격이 달라 왼쪽 머리글도 다릅니다.

```
받은목양   No. · 이름 · 그룹 · 학년 · 합계 · [주차별 문자/통화/성경/만남] …
한목양     No. · 이름 · 담당 · 합계 · [주차별 문자/통화/성경/만남] …
```

둘 다 **최근 6주**만 보여 줍니다. 지난 기록은 `기록` 탭에 모두 남아 있습니다.

히트맵은 파랑 한 가지 색으로 옅은 쪽 → 진한 쪽입니다 (1건 → 4건 이상).
색상보다 **밝기가 한 방향으로만 간다**는 점이 중요합니다. 그래야 진하기가 곧 횟수로 읽힙니다.

요약 두 장은 사람이 직접 고칠 시트가 아니라 매번 통째로 다시 그려집니다.
손으로 메모할 내용이 있으면 별도 탭을 만들어 쓰세요. `기록` 시트만 살아 있으면 요약은 언제든 복구됩니다.

**주차 기준**: 한국 시간, 일요일(주일)에 시작해서 토요일에 끝납니다. 주차 키는 그 주 일요일 날짜입니다.

**그룹과 학년**

그룹은 `학교급 × 성별` 여섯 가지입니다. 요약표에서도 이 순서로 섭니다.

```
초등학생 형제 · 초등학생 자매 · 중학생 형제 · 중학생 자매 · 고등학생 형제 · 고등학생 자매
```

학년은 `초1~초6` `중1~중3` `고1~고3`, 그리고 `미분류` 입니다.
새 학생을 넣을 때는 `학생명단` 탭에 이름 · 그룹 · 학년 한 줄만 추가하면 되고, 코드는 건드릴 필요 없습니다.

이 두 값이 하는 일:
- 요약표 행 순서를 기존 종이 양식과 똑같이 맞춥니다.
- 동명이인을 구분합니다. 같은 그룹에 이름이 똑같은 학생이 학년만 다르게 있을 수 있습니다.
- **이름 매칭을 좁힙니다.** 봉사자가 담당 그룹을 골라 두면, 후보가 여럿일 때 담당 그룹부터 봅니다.
  덕분에 고등학생 자매 담당이 이름만 적어도 같은 이름의 중등 학생이 아니라 담당 그룹의 학생으로 잡힙니다.
  담당 그룹에 없으면 다른 그룹에서도 찾고, 그래도 애매하면 화면에서 누구인지 고르게 합니다.

## 0. 먼저 화면만 둘러보기 (선택)

구글 계정 설정 전에 앱을 먼저 보고 싶다면:

```bash
npm install && echo "DEMO_ROSTER=1" > .env.local && npm run dev
```

`data/roster.ts` 의 명단으로 화면이 뜹니다. 저장은 실제 시트가 있어야 되므로, 둘러본 뒤 아래 1번부터 진행하세요.

## 1. 구글 시트 준비

1. 새 구글 시트를 만들고 이름을 정합니다 (예: `2026 주중 목양 현황`).
2. 주소창에서 문서 ID를 복사해 둡니다.
   `https://docs.google.com/spreadsheets/d/` **`이 부분`** `/edit`
3. 탭은 미리 만들 필요 없습니다. 서비스가 처음 실행될 때
   `봉사자명단` / `학생명단` / `기록` / `받은목양` / `한목양` 을 알아서 만듭니다.

## 2. 서비스 계정 만들기 (10분, 한 번만)

서비스가 시트에 쓰려면 &ldquo;로봇 계정&rdquo;이 하나 필요합니다.

> **요금**: Sheets API는 무료입니다. 공식 문서 원문은
> "All standard use of the Google Sheets API is available at no additional cost."
> ([Usage limits](https://developers.google.com/workspace/sheets/api/limits))
> **신용카드 등록도 필요 없습니다.** Google Cloud Console이 곳곳에서 "무료 크레딧 $300" 배너와
> 결제 설정을 권하지만, Sheets API만 쓸 거라면 결제 설정은 건너뛰면 됩니다.
>
> 할당량은 읽기·쓰기 각각 **분당 300회/프로젝트, 분당 60회/사용자**입니다.
> 서비스 계정은 "사용자 1명"으로 계산되고 저장 1회에 API 요청이 8~10건 나가므로,
> 여섯 명 이상이 같은 1분 안에 몰아서 저장하면 이론상 걸릴 수 있습니다. 걸려도 잠시 후 다시 누르면 됩니다.
> (2026년 후반부터 예고된 과금은 이 할당량을 **초과한 분**에 대한 것이라 이 규모와는 무관합니다.)

1. [Google Cloud Console](https://console.cloud.google.com/) 접속 → 새 프로젝트 생성 (예: `shepherd-stats`)
2. **API 및 서비스 → 라이브러리** 에서 `Google Sheets API` 검색 → **사용 설정**
3. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → 서비스 계정**
   - 이름은 아무거나 (예: `shepherd-bot`), 역할은 지정하지 않아도 됩니다.
4. 만들어진 서비스 계정을 클릭 → **키 → 키 추가 → 새 키 만들기 → JSON** → 파일이 다운로드됩니다.
5. JSON 파일 안의 `client_email` 과 `private_key` 두 값을 씁니다.

## 3. 시트 공유 설정

- 1번에서 만든 시트를 열고 **공유** 를 누릅니다.
- 서비스 계정 이메일(`...@....iam.gserviceaccount.com`)을 **편집자**로 추가합니다. ← 이게 없으면 저장이 실패합니다.
- 함께 관리할 사람 2~3명도 **편집자**로 추가합니다.
- **일반 액세스**를 `링크가 있는 모든 사용자` + **뷰어**로 바꿉니다.
  → 링크만 있으면 누구나 볼 수 있고, 고칠 수 있는 사람은 지정한 몇 명뿐입니다.

## 4. 로컬에서 실행

```bash
npm install
```

`.env.example` 을 복사해 `.env.local` 을 만들고 값을 채웁니다.

```bash
cp .env.example .env.local
```

| 환경변수 | 값 |
| --- | --- |
| `GOOGLE_SHEET_ID` | 1번에서 복사한 문서 ID |
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` | JSON 키의 `client_email` |
| `GOOGLE_PRIVATE_KEY` | JSON 키의 `private_key` 값을 그대로. `\n` 이 들어간 채로 큰따옴표로 감쌉니다. |
| `APP_PASSWORD` | 웹앱 공용 비밀번호. **비워 두면 링크를 아는 누구나** 입력할 수 있습니다. |
| `DEMO_ROSTER` | 화면만 둘러볼 때 `1`. 배포 환경에는 넣지 마세요. |

명단을 시트에 한 번에 넣습니다. (`data/roster.ts` 내용 — 예시 명단)

```bash
npm run seed
```

이미 명단이 있으면 멈춥니다. 덮어쓰려면 `npm run seed -- --force` 를 쓰세요.
&mdash; 다만 `--force` 는 명단 두 장을 **통째로 새로 씁니다.** 시트에서 손으로 채운 담당 배정이나
추가한 학생이 있다면 함께 날아가니, 그럴 때는 시트에서 직접 한 줄 추가하는 편이 안전합니다.

이후 명단 관리(전입·전출·학년 올리기·담당 배정)는 구글 시트에서 직접 하면 됩니다.
`봉사자명단` 의 **담당그룹** 칸에 미리 적어 두면(`고등학생 자매` 처럼, 여러 개면 쉼표로)
봉사자가 앱에서 담당을 고르는 단계를 건너뜁니다.

시트에서 명단만 고쳤을 때 요약표를 바로 반영하려면:

```bash
npm run refresh
```

기록을 저장할 때마다 자동으로 다시 그려지므로, 평소에는 쓸 일이 없습니다.

```bash
npm run dev       # http://localhost:3000
npm test          # 파서 / 이름 매칭 / 주차 계산 / 요약표 테스트
npm run typecheck # 타입 검사
npm run build     # 배포 전 빌드 확인
```

## 5. Vercel 배포

1. 이 저장소를 GitHub에 올립니다.
2. [vercel.com](https://vercel.com) 에 GitHub으로 로그인 → **Add New → Project** → 저장소 선택.
3. Framework는 Next.js로 자동 인식됩니다. 빌드 설정은 건드릴 필요 없습니다.
4. **Environment Variables** 에 위 표의 네 가지를 그대로 넣습니다.
   - `GOOGLE_PRIVATE_KEY` 는 JSON에 적힌 문자열 그대로 (`-----BEGIN PRIVATE KEY-----\n...` 형태) 붙여넣으면 됩니다.
5. **Deploy**. 끝나면 `프로젝트이름.vercel.app` 주소가 나옵니다. 이 링크를 단톡방에 공유하면 됩니다.

- 무료 Hobby 플랜으로 충분합니다.
- 이후 `main` 브랜치에 push하면 자동으로 다시 배포됩니다.
- 환경변수를 바꿨을 때는 Vercel에서 **Redeploy** 를 한 번 눌러야 반영됩니다.
- 도메인이 있다면 **Settings → Domains** 에서 연결할 수 있습니다.

## 사용법

1. 링크 접속 → (비밀번호를 걸었다면) 비밀번호 입력
2. 봉사자 명단에서 **본인 이름**을 고릅니다.
3. **담당 그룹**을 고릅니다. 이름 매칭을 좁히는 힌트일 뿐이라 건너뛰어도 되고, 여러 개 골라도 됩니다.
   시트의 `봉사자명단` 에 이미 적혀 있으면 이 단계는 안 나옵니다.
   여기까지가 기기에 저장되어, 다음부터는 바로 채팅 화면이 열립니다.
4. `이번 주` / `지난주` 중 어느 주차에 기록할지 고릅니다.
   두 버튼에 각자의 날짜와 요일(`8/9(주일)~8/15(토)`)이 함께 적혀 있어 눌러 보지 않아도 구분됩니다.
   고른 주차는 바로 아래 `지금 이번 주에 기록 중` 줄, 미리보기 머리말, 저장 버튼(`이번 주로 저장`)에
   한 번씩 더 나오니 엉뚱한 주차에 넣을 일이 없습니다.
5. 평소처럼 적어서 **정리** 를 누르면, 이렇게 저장할 거라고 미리 보여 줍니다.
   - `하늘` → `김하늘`, `보람이` → `이보람` 처럼 성이나 호칭을 빼고 적어도 찾아 줍니다.
   - 같은 이름이 여러 명이면 학년을 보여 주고 고르게 합니다. 고르기 전에는 저장되지 않습니다.
   - 이름이 학생 명단에 없으면 `새 학생` 줄이 뜨고, **성 · 이름 · 그룹 · 학년을 그 자리에서 정합니다.**
     - **성/이름**은 적으신 글자로 미리 나눠 둡니다. `김하늘` → 성 `김` / 이름 `하늘`,
       `남궁하늘` → 성 `남궁` / 이름 `하늘`. 두 글자(`보람`)는 성을 빼고 부른 경우가 훨씬 흔해 **성 칸을 비워 두니**,
       아시는 성을 적어 주세요. `김구` 처럼 성 + 외자 이름이면 `김` 을 성 칸으로 옮기면 됩니다.
       저장될 이름은 줄 위에 `'보람' → 이보람` 처럼 미리 보여 줍니다.
     - **학년 선택지는 고른 그룹에 맞춰 바뀝니다** (초등학생이면 `초1~초6`). 담당 그룹이 하나면 그룹은 미리 채워집니다.
     - 네 칸이 다 차기 전에는 저장되지 않으니, 시트에 `미분류`로 남는 일이 없습니다.
       정말 모를 때만 `학년 모름` 을 고르면 되고, 그 학생은 시트 비고에 `학년 확인 필요` 로 표시됩니다.
   - 잘못 잡힌 이름은 `×` 로 뺍니다.
6. **시트에 저장** 을 누르면 기록되고 요약 두 장이 다시 그려집니다.
7. 잘못 넣었으면 상단 **내 기록** 에서 지울 수 있습니다.

### 알아 두면 좋은 것

- 같은 주 / 같은 봉사자 / 같은 항목 / 같은 학생은 중복으로 보고 건너뜁니다. 두 번 보내도 안전합니다.
- **새 학생은 `학생명단` 의 제 자리에 끼어 들어갑니다.** 맨 아래에 붙지 않습니다.
  중학생 형제를 추가하면 중학생 자매부터 아래로는 한 칸씩 밀리고, 같은 그룹 안에서는 학년 순서를 지킵니다.
- **잘못 추가한 학생은 기록을 지우면 명단에서도 사라집니다.** `내 기록` 에서 그 학생의 마지막 기록을 지우면,
  앱이 넣었던 명단 행도 함께 지워집니다. 처음부터 명단에 있던 학생이나 손으로 넣은 학생은
  기록이 하나도 없어도 그대로 남습니다 (비고의 `앱에서 추가` 표시로 구분합니다).
- 인식하는 표현
  - 문자: `문자` `카톡` `톡` `메시지` `문자메시지` `sms` `dm`
  - 통화: `통화` `전화` `콜` `call`
  - 성경: `성경` `말씀` `통독` `큐티` `qt` `성경나눔`
  - 만남: `만남` `심방` `미팅` `모임` `식사` `대면`
- 구분자는 `-` `–` `:` `)` 아무거나, 이름 구분은 `,` `/` `·` 또는 띄어쓰기로 됩니다.
- `만남 - 없음` 처럼 적으면 그 항목은 비워 둡니다.
- 문장으로 보이는 인사말은 이름으로 세지 않고 &ldquo;해석하지 못한 내용&rdquo; 으로 알려 줍니다.
- 입력창에서 `⌘/Ctrl + Enter` 로도 보낼 수 있습니다. `Enter` 는 줄바꿈입니다.

## 구조

```
app/
  page.tsx              채팅 UI (봉사자 선택 · 담당 선택 · 미리보기 · 저장 · 내 기록)
  api/config/route.ts   첫 화면 설정 (비밀번호 필요 여부, 주차 목록, 시트 링크)
  api/roster/route.ts   봉사자·학생 명단 조회
```
